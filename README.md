#### Data: 

##### Raw data: ML-CLi-Rev2.xlsx

##### Processed data: cleaned_df.csv

##### Ten Features subset: k_10_df.csv

##### EDA.ipynb : Conducted exploratory data analysis and prepped the data, the output was cleaned_df.csv

##### baseline.ipynb : Baseline modeling 

##### k9_modeling.ipynb : Tested 9 features, came back to all the features

##### k10_modeling.ipynb : Not empty but irrelevant, after k9 modeling found it to be unnecessary to test k10 

##### tuning.ipynb : Final tuning of the chosen model
